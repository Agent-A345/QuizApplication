## 🎯 Online Quiz Application

An interactive, category-based quiz platform built using HTML, CSS, and JavaScript. Users can choose from multiple quiz categories, answer timed questions, view their score, and retry quizzes to improve performance.

## 🚀 Features
1. **Category Selection** – Choose from General Knowledge, Science, Sports, History, or Geography.
2. **Multiple Choice Questions** – 10 curated questions per category.
3. **Live Score Display** – Score updates in real-time after each answer.
4. **Correct/Incorrect Feedback** – Immediate visual feedback after answering.
5. **Result Summary** – Final score with motivational message.
6. **Replay Options** – Retry same category or pick a new one.
7. **Responsive Design** – Fully responsive for desktop and mobile devices.
